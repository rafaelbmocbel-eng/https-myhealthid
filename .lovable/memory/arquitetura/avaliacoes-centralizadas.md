- Sidebar profissional contém apenas: Agenda, Pacientes, Eventos, Dashboard, Configurações
- COB° ZERO, Método Identidade e Studio Personal ID NÃO têm mais páginas próprias (/metodo-identidade, /cob-zero, /studio-personal-id foram removidas)
- São apenas tipos de avaliação acessíveis dentro do perfil do paciente (aba Avaliações)
- Cadastro do paciente é único e global — disponível para qualquer serviço
- Rotas legadas (/metodo-identidade, /cob-zero, /studio-personal-id, /avaliacoes, /protocolos, /relatorios) redirecionam para /pacientes
- Componentes wizard (CobZeroWizard, MyIDWizard, StudioWizard) e dashboards continuam intactos — só as páginas-hub foram removidas
